# Case Study 3 - İş Zekası (BI) Dashboard

## 📋 Proje Hakkında
Bu proje, İş Zekasına Giriş (BI) dersi kapsamında hazırlanmış bir Power BI dashboard çalışmasıdır. Satış verileri üzerinde veri temizleme, modelleme ve görselleştirme yapılmıştır.

## 📊 Dashboard Sayfaları
| Sayfa | İçerik |
|-------|--------|
| 1. Yönetim Özeti | KPI kartları, satış trendi, bölge bazlı satış |
| 2. Müşteri Segmentasyonu | Müşteri bazlı satış tablosu, temsilci dağılımı |
| 3. Bölgesel Analiz | Bölge karşılaştırması, ortalama fatura analizi |
| 4. Ürün Analizi | Ürün ailesi dağılımı, Top 10 ürün, fiyat trendi |
